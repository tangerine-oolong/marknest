# 常见问题

## 使用

**「应用到 Chrome」和「导出书签 HTML」有什么区别？**
扩展版用前者——直接改浏览器里的书签，改之前会给你看操作清单并自动备份。
网页版只能后者——导出一个 HTML，你自己去书签管理器导入（追加，不覆盖）。

**我误删了书签怎么办？**
先 `⌘Z`（撤销栈 200 步）。撤销不动了就去回收站点「恢复」。
已经"彻底删除"或已应用到浏览器，就用扩展的备份回滚，或拿你之前导出的书签 HTML 重新导入。

**为什么看不到 `常用` / `从未访问` 标签？**
这两个需要浏览历史，只有扩展形态能拿到。网页版导入的是浏览器导出的 HTML，里面没有使用记录字段。

**搜索是不是只搜当前分类？**
默认搜**全部**。搜索框下面的「仅当前分类」勾上才限定范围。

**为什么我打开某个分类，里面的书签比实际少？**
默认视图只显示该分类**本层**的书签，子分类以文件夹行显示。勾上工具栏的「包含子分类」才会把子分类内容一起平铺。

**导入 Chrome 后出现了「已导入」文件夹，能去掉吗？**
把里面的分类逐个拖到书签栏根目录，再删掉空掉的「已导入」。Chrome 的导入行为固定如此，不是本工具造成的。

**「其他书签」里的东西去哪了？**
本工具会一并读取（书签栏 + 其他书签 + 移动书签）。但导出后 Chrome 只会把内容放进书签栏，
所以原「其他书签」的条目会变成两份：新的副本 + 原来的原件。确认副本齐全后手动删原件。

**书签很多（几千条）会卡吗？**
界面是一次性渲染全表的，实测几千条量级下滚动和筛选都可用；如果上万条建议先用搜索/标签缩小范围再批量操作。

## 失效检测

**为什么有的网址标「http 未测」？**
非 https 网址会被浏览器按混合内容拦截，无法判断，也不算失效。

**为什么内网网址全部显示疑似失效？**
你在能访问内网的网络之外检测的。连上公司网络/VPN 再跑一次。

**能识别 404 吗？**
不能。跨域限制下只能判断"能不能连上"，拿不到状态码。所以 `疑似失效` 的含义是"域名解析失败或连不上"。

## 安装与开发

**Edge / Brave 能用吗？**
能，Chromium 内核都支持「加载已解压的扩展程序」。

**Firefox 呢？**
扩展形态需要改 manifest（Firefox 用 `browser_specific_settings` 和不同的权限模型），暂未适配。
网页版在 Firefox 上完全可用——它只依赖你导出的书签 HTML。

**Safari 支持吗？**
不支持。Safari 无法导入 HTML 书签文件，只能从 Chrome/Firefox 整体迁移。

**我改了代码，为什么页面没变化？**
改 `src/` 后必须重新 `python3 tools/build.py`，页面用的是 `dist/` 里的产物。

**怎么加一种新的数据源（比如某个云端书签服务）？**
照着 `src/adapters/file-adapter.js` 实现 `load() / saveDraft() / canApply` 三个接口，
在 `src/ui/app.js` 的 `boot()` 里注册即可，核心逻辑不用动。

**测试怎么跑？**
`python3 tests/run-tests.py`（静态）+ 浏览器打开 `tests/browser-tests.html`（功能，应显示"全部通过"）。
