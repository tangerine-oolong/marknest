# 安装 Chrome 扩展（开发者模式加载）

当前分发方式是「加载已解压的扩展」，适合自测和极客用户；上架 Chrome 应用商店是后续计划。

## 步骤

1. 构建扩展包：
   ```bash
   git clone <本仓库>
   cd marknest        # 换成你 clone 下来的目录名
   python3 tools/build.py      # 生成 dist/extension/
   ```
2. 打开 `chrome://extensions`
3. 右上角开启 **开发者模式**
4. 点 **加载已解压的扩展程序**，选择 `dist/extension/` 目录
5. 点击工具栏上的图标 → 整理台会在新标签页打开，并直接读取你的书签

Edge / Brave / Arc 等 Chromium 内核浏览器步骤相同（Edge 是 `edge://extensions`）。

## 权限弹窗怎么看

安装时 Chrome 会提示它可以「读取和管理书签」「读取浏览记录」。用途分别是：

- **书签**：这就是工具本身——读出来给你整理，写回去完成整理
- **浏览记录**：只用来算"哪些书签你经常用、哪些从没访问过"。拒绝的话这两个标签不显示，其余功能不受影响
- **访问所有网站的数据（可选）**：只有你主动点「检测失效链接」时才会请求授权

详见 [permissions.md](permissions.md)。

## 应用到 Chrome 之前会发生什么

1. 你在界面里的所有操作都只改**本地草稿**，浏览器书签不受影响
2. 点「应用到 Chrome」→ 弹出操作清单：新建几个分类、移动几条、删除几条
3. 确认后：**先把当前浏览器书签真实状态存成备份**（保留最近 5 份），再按安全顺序执行
   （先建分类 → 建条目 → 改名 → 移动 → 删条目 → 从最深开始删分类）
4. 中途某条失败不会中断整体，结束后列出失败项供你重试
5. 想反悔：备份列表里点「回滚」，会按备份重建

## 常见问题

**看不到图标** → 点工具栏的拼图图标，把 Marknest 固定。

**改了书签但浏览器里没变** → 你还没点「应用到 Chrome」，改动仍在草稿里。

**打开页面显示的是"导入书签 HTML"引导页** → 说明扩展权限没生效或 `chrome.bookmarks` 不可用，
页面会自动降级成网页版。到 `chrome://extensions` 看是否有错误提示，重新加载扩展试试。

**升级版本后草稿丢了** → 草稿存在扩展自己的 storage 里，正常会保留；保险做法是升级前用「保存进度」导出 JSON。
