# 权限说明

Manifest V3，扩展声明的权限刻意保持最小。

| 权限 | 类型 | 为什么需要 | 拒绝会怎样 |
|---|---|---|---|
| `bookmarks` | 必需 | 读取书签树、把整理结果写回浏览器 | 无法使用，工具没有意义 |
| `storage` | 必需 | 保存草稿、自动备份（最近 5 份）、界面偏好（列宽、语言等） | 无法保存进度 |
| `history` | 必需（可拒绝） | 计算每条书签的访问次数与最后访问时间，用于 `常用` / `从未访问` / `过时` 标签 | 这两个标签不显示，`过时` 退化为按添加年份判断；其余功能完全正常 |
| `<all_urls>` | **可选，按需申请** | 只有你点「检测失效链接」时才弹窗请求，用于逐个访问网址判断能否连通 | 不装这个功能就是不可用，其他不受影响 |

## 关于 `history`

Chrome 导出的书签 HTML 里**没有**任何使用记录字段，所以"哪些书签你早就不看了"这个最有用的信息，
只有扩展形态能通过浏览历史算出来。这是申请 `history` 的唯一理由。

具体行为：

- 只在页面里点「读取使用度」或首次加载时拉取一次，结果缓存在扩展本地 6 小时
- 只读取 `url`、`visitCount`、`lastVisitTime` 三个字段，不读取页面内容、不上传
- 缓存放在 `chrome.storage.local`，卸载扩展即随扩展数据一起删除

## 关于 `<all_urls>`

失效检测会向每个书签网址发一个请求（`mode: 'no-cors'`，只判断能否建立连接）。
因为要跨域访问任意站点，Chrome 要求显式授权，所以：

- 安装时**不会**申请，只有你点「检测失效链接」按钮时才弹窗
- 拒绝后工具照常工作，只是没有 `疑似失效` 标签
- 检测过程可中断，进度可见

## 商店上架前的合规提示

Chrome 应用商店会审查"单一用途"和权限必要性。本工具只做书签整理一件事，
不夹带搜索增强、统计、云同步等功能；`history` 与 `<all_urls>` 的用途在上表里已逐条说明，
可直接用于填写商店的权限 justification。
