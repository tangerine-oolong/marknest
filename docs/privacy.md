# 隐私承诺

## 会发生的事

- 所有解析、分类、排序、导出都在**你自己的浏览器里**完成，代码就是本地那几个 JS 文件，可自行审阅
- 扩展形态下，书签数据存在 `chrome.storage.local`（浏览器扩展本地存储），草稿和备份也在这里
- 网页版形态下，进度存在浏览器 `localStorage`；`file://` 下不可用时界面会明确提示你改用「保存进度」导出 JSON

## 不会发生的事

- **没有任何服务器**：不含埋点、统计、崩溃上报、广告、第三方 SDK，也没有远程代码
- **不发起网络请求**，除了两个你主动触发的功能：
  1. 「检测失效链接」→ 逐个访问你的书签网址（跨域限制下只判断能否连上，不读取页面内容）
  2. 无其他
- **不读取**：浏览历史的具体记录内容（只取 url / visitCount / lastVisitTime）、Cookie、密码、表单、下载记录

## 数据什么时候被清除

- 卸载扩展 → 扩展本地存储随之删除
- 网页版 → 清理浏览器站点数据即删除；换设备前请自行「保存进度」导出 JSON
- 备份只保留最近 5 份，超出自动丢弃最旧的

## 给开发者的提醒

仓库里带了一个泄露守卫：

```bash
python3 tools/leak-guard.py
```

它会扫描仓库和构建产物里是否混入了真实书签数据（内网域名、真实邮箱等）。
**提交或发布前请务必跑一次**——把带真实数据的导出文件、截图、演示视频放进公开仓库是最容易犯的错。
`.gitignore` 已经排除了常见的导出文件名模式，但挡不住你改名提交。
