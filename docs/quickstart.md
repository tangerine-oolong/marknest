# 快速上手（网页版）

适用于不想装扩展、或用 Firefox 的场景。全程本地处理。

## 第 1 步 · 导出浏览器书签

**Chrome / Edge / Brave 等 Chromium 内核**

1. 按 `⌥⌘B`（macOS）或 `Ctrl+Shift+O`（Windows / Linux）打开书签管理器
2. 点页面内右上角的 `⋮`（不是浏览器窗口右上角那个）
3. 选 **导出书签** → 保存成一个 HTML 文件（类似 `bookmarks_2026_10_7.html`）

**Firefox**

书签管理器（`Ctrl+Shift+B`）→ 右上角「导入和管理书签」→ **导出书签…**

> 导出的 HTML 里不含"最后访问时间/访问次数"，所以网页版不会显示 `常用`、`从未访问` 标签，
> `过时` 会退化成「5 年以上未整理」。这是数据源限制，不是 bug。

## 第 2 步 · 导入本工具

打开 `dist/web/index.html`（双击即可），把刚才的 HTML 文件选进来。
想先看看效果，点「载入演示数据」（66 条合成书签，全是 example.com 假域名）。

进度会自动存在浏览器本地存储，下次打开点「恢复上次进度」继续。

## 第 3 步 · 整理

最常用的几条路径：

- **先清理**：点标签 `过时` 或 `疑似失效` → 「选中当前筛选结果」→ 删除。删的东西进回收站，可恢复。
- **找东西**：搜索框默认搜**全部**书签，结果会标出每条在哪个分类。
- **归类**：点 ✦ 打开建议面板 → 按站点聚类（"这个域名我收藏了 20 条"）或写规则（域名含 X → 归到 A/B）。
- **收拾结构**：建议面板的「结构整理」里一键压平过深层级、合并只有 1 条书签的碎片分类。
- **手滑了**：`⌘Z` 撤销，最多 200 步。

## 第 4 步 · 导出定稿

点 **导出书签 HTML**。如果还有需要确认的体检项，会先弹出体检报告，处理完再导出。
导出文件名 `bookmarks-final.html`。

## 第 5 步 · 导回浏览器

1. **先备份**：书签管理器 `⋮` → 导出书签，存一份当前状态（这是你唯一的回滚手段）
2. 同一菜单 → **导入书签** → 选 `bookmarks-final.html`
3. 书签栏会出现一个新的「已导入」文件夹，里面是你的新结构。**你原有的书签一条都不会掉**——导入是纯追加
4. 把「已导入」里的分类拖到书签栏根目录，再删掉旧的顶层文件夹和「其他书签」里的重复内容
5. 确认没问题后再清理第 1 步的备份文件

## 三个坑，提前知道

- **重复**：原来在「其他书签」的内容，导入后会以副本形式出现在书签栏的「已导入」里，而原件还在「其他书签」。需要自己删原件。
- **同步**：开着浏览器账号同步时，导入和删除都会推到其它设备。**中途不要关闭再打开同步开关**——重新开启会把服务器上的旧数据合并回来，造成重复。
- **添加时间**：导入会把书签的"添加时间"重置为导入时刻。
