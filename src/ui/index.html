Marknest 书签整理台

先看清，再动手

1导出浏览器书签为 HTML（Chrome：按 ⌥B 打开书签管理器 → 右上角 ⋮ → 导出书签）
2把那个 HTML 文件选进来，全程本地解析，不上传
3整理满意后导出定稿 HTML，再导回浏览器；导回是追加，不会覆盖现有书签

扩展读取书签失败

常见原因：扩展权限未生效（到 chrome://extensions 看该扩展卡片有没有红色「错误」），或这个页面不是从扩展图标打开的（地址栏应以 chrome-extension:// 开头）。

本工具不联网、不上传任何书签数据；「检测失效链接」是唯一会主动访问网址的功能，需要你明确点击才会开始。
